# Sales ETL Pipeline

Автоматизированный ETL-пайплайн на Python для очистки, валидации и обогащения данных о продажах с последующим построением аналитических SQL-витрин в SQLite.

## Архитектура и этапы работы
1. **Extract**: загрузка сырых транзакционных данных (`test.csv`) и справочника клиентов (`test2.csv`).
2. **Transform**:
   - Нормализация строковых идентификаторов и текстовых полей (очистка пробелов, приведение к единому регистру).
   - Обработка аномалий и пропусков (замена некорректных цен на медианные значения, заполнение пропусков дефолтными параметрами, парсинг дат).
   - Дедупликация записей и контроль целостности данных при объединении таблиц через `assert`-проверки.
   - Расчет бизнес-метрик (`revenue`) и выделение отчетных периодов.
3. **Load**: загрузка очищенного слоя данных и формирование 3 аналитических витрин в БД `etl.db`:
   - `mart_monthly_sales` — динамика выручки и количества заказов по месяцам и регионам.
   - `mart_top_customers` — рейтинг топ-5 клиентов по объему покупок.
   - `mart_products` — продуктовая аналитика по выручке и объему продаж.

## Стек технологий
* **Python 3** (`pandas`, `sqlite3`)
* **SQL** (SQLite)

## Быстрый старт
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите пайплайн: `python etl_pipeline.py`
